## 👋 About Me

I'm a **Product Security Engineer at Stryker** with ~3 years of experience breaking and hardening software, from web apps to the medical devices that run in hospitals.

- 🔐 **Day job:** penetration testing across **web, API, thick-client, IoT and embedded medical devices**
- 📦 **Compliance:** building **FDA SBOM** workflows for medical-device software
- 🐍 **Automation:** writing **Python** tooling to take the grunt work out of security testing
- 🤖 **Exploring:** **AI red teaming** and adversarial testing of LLM-powered systems
- 🎓 **Education:** M.Tech in Information Security, **VIT Vellore** · B.Tech in IT, **Academy of Technology**
- 🐧 **Fun fact:** my daily driver is **Pop!_OS**
